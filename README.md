# Де «живуть» змінні та дані в програмі (C++ / ESP32)

Кожній змінній або шматочку даних у пам'яті мікроконтролера відведено своє спеціальне місце залежно від їхнього типу та способу оголошення:

* **Flash (ПЗП / Побуткова пам'ять):**
  * Сам компільований бінарний код програми (машинні інструкції).
  * Константи (`const`) та текстові литерали (рядкові константи на кшталт `"Hello, World!"`).
  * Дані, які не повинні змінюватися під час виконання програми.

* **Стек (Stack):**
  * Локальні змінні, які створюються всередині функцій (наприклад, `int temp = 25;`).
  * Параметри, що передаються у функції.
  * Пам'ять тут виділяється і звільняється автоматично в момент виходу з області видимості функції.

* **Купа (Heap):**
  * Динамічно виділена пам'ять (наприклад, за допомогою операторів `new` / `malloc` або складні об'єкти).
  * Вимагає ручного керування (або використання розумних вказівників), інакше може статися витік пам'яті.

* **Секція `.bss`:**
  * Глобальні та статичні змінні (`static`, глобальні змінні), які **не мають** початкового значення або ініціалізовані нулем за замовчуванням.
  * Під час запуску програми система автоматично заповнює цю область нулями.
