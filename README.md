# Дослідження пам'яті та таймерів у C++ (ESP32)

Цей репозиторій містить практичні приклади та теоретичні пояснення ключових концепцій програмування мікроконтролерів. Головна мета — продемонструвати правильну роботу з таймерами, розподілом пам'яті та розуміння поведінки типів даних.

## 1. Архітектура пам'яті: Де «живуть» змінні

Кожній змінній або шматочку даних у пам'яті мікроконтролера відведено своє спеціальне місце залежно від їхнього типу та способу оголошення:

* **Flash (ПЗП / Флеш-пам'ять):** Тут зберігається сам компільований бінарний машинний код програми. Також сюди (у секцію `.rodata`) потрапляють константи (`const`), текстові літерали (на кшталт `"Hello, World!"`) та дані, які ніколи не змінюються під час виконання програми.
* **Стек (Stack):** Місце для локальних змінних, які створюються всередині функцій (наприклад, `int temp = 25;`), та параметрів, що передаються у ці функції. Пам'ять тут виділяється і звільняється автоматично в момент виходу з області видимості функції.
* **Купа (Heap):** Область для динамічно виділеної пам'яті (за допомогою операторів `new` / `malloc`, або `ps_malloc` для зовнішньої PSRAM). Вимагає ручного керування, інакше виникає ризик витоку пам'яті (memory leak).
* **Секція `.data`:** Тут зберігаються глобальні та статичні змінні, які при створенні були явно ініціалізовані **не нульовим** значенням (наприклад, `int myVar = 42;`). Ця секція фізично зберігається у Flash, але під час запуску мікроконтролера копіюється в оперативну пам'ять (RAM).
* **Секція `.bss`:** Тут розміщуються глобальні та статичні змінні, які **не мають** початкового значення або ініціалізовані **нулем** (наприклад, `int myCounter;` або `int myCounter = 0;`). Під час запуску програми система автоматично заповнює цю область оперативної пам'яті нулями.
